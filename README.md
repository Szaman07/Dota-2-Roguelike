# A Dice-Based Tournament Roguelike Deck Builder (Dota 2)

CSE311 (Database Management Systems, NSU) course project. A TI-run roguelike where you draft pro players and heroes, then play a group stage and a double-elimination bracket against real tier-1 winner and finalist rosters. Planned stack: PHP + MySQL 8.

Status: design stage, no game code yet.

## Layout
- `docs/project/` project pack (start with `claude_code_context_prompt.md` for a short Claude Code brief): proposal, game outline, audit, open questions, coursework map, build plan, schema drafts (`schema/`)
- `docs/research/` research notes and design docs
- `docs/guides/` learning guides
- `data/` OpenDota pro match pull, wiki mechanics, dotaconstants, processed pre-fills and scripts (see `data/README.md`)
- `research/` early research notes
- `uploads/` reference screenshots shared in the project
